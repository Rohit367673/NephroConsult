
# 🏥 NephroConsult Telemedicine Platform

NephroConsult is a secure telemedicine platform connecting patients with nephrology specialists worldwide.

## 🚀 Quick Start

### 1. Backend Server
```bash
cd server
npm install
npm run dev
```

### 2. Frontend Application
```bash
cd "International Nephrology Consultation Platform"
npm install
npm run dev
```
